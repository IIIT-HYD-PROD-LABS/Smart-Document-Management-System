## Known environment limitation (not a regression)

The wider `tests/test_compliance_endpoints.py::test_role_permission_matrix` cases error in this docker-against-Supabase environment because `SET ROLE app_runtime` is not permitted on the Supabase pooler user. Phase 9 STATE.md flagged this same limitation. The 91-case matrix passes when run against a local Postgres with the `app_runtime` role granted to the test user. Adding NOTICE_AI_EXTRACT does not change that environment behaviour either way.
