HOW SECURITY WORKS

JWT + opaque refresh · OAuth · 7×12 RBAC · RLS · Audit-immutable · Rate-limit · OWASP-aware

★ REMEMBER

  • 4 overlapping layers
  • RBAC at route, RLS at DB
  • Bcrypt + JWT (HS256)
  • Refresh-token rotation
  • Audit trigger = unbreakable

2 AUTH FLOWS

LOCAL
  /register → bcrypt(password) → row inserted
  /login    → verify bcrypt   → access + refresh
  /refresh  → rotate refresh  → reuse-detect → nuke

OAUTH (Google · Microsoft)
  /oauth/google     → state JWT (10 min · CSRF)
  provider redirect → /callback/google
  backend creates user (or links · refuses local-pwd link)
  redirect → /oauth/callback?code=&token=  (2-min JWT)
  POST /oauth/exchange   ← single-use jti via Redis
  → access + refresh

4 REFRESH ROTATION

SELECT … FROM refresh_tokens
   WHERE token = ?
   FOR UPDATE          ← row lock

if revoked:
   UPDATE refresh_tokens
      SET is_revoked = TRUE
      WHERE user_id = ? AND is_revoked = FALSE
   → 401 "reuse detected"   ← all sessions killed

if expired: revoke + 401
otherwise:
   issue new refresh; old.replaced_by = new
   commit

7 ROW LEVEL SECURITY

incoming request
   │ X-Client-Id: 42
   ▼
TenantContextMiddleware
   sets ContextVar  current_client_id = 42
   ▼
route handler → Depends(get_db)
   ▼
SQLAlchemy before_cursor_execute  (every statement)
   SET app.current_client_id = 42
   SET app.user_id           = jwt.sub
   SET app.cross_client_mode = false
   SET ROLE app_runtime
   ▼
SELECT * FROM compliance_notices
   ──► RLS rewrites: …AND client_id = 42

No tenant header = no set_config = policy denies all rows. Fail-closed.

9 RATE LIMITING (slowapi)

  • Per-IP + per-route limits
  • RATE_LIMIT_AUTH on register/login/refresh/logout/oauth
  • OAuth provider URL endpoints capped at 30/min
  • Storage: in-memory by default; Redis-backed in prod
  • 429 returned with Retry-After

10 UPLOAD HARDENING

  • Magic-byte check — not just extension
  • SVG rejected for logo upload (XSS)
  • Logo cap: 340 KB base64 data URL
  • Path-traversal guard via _validate_path_inside_upload_dir
  • MAX_FILE_SIZE_MB enforced
  • OCR worker re-validates before open()

11 SECRETS & CRYPTO

  • SECRET_KEY validated: ≥32 chars, ≥10 unique
  • OAuth client secrets in env only
  • ai_credentials table stores Fernet-encrypted BYOK keys
  • Encryption cipher is INFRA-06 module
  • Plaintext NEVER returned to API consumers
  • Bcrypt cost factor default (12)

EXAM ANGLES

  • Q: How do you prevent tenant data leakage? X-Client-Id → ContextVar → before_cursor_execute → SET app.current_client_id → RLS policy + fail-closed.
  • Q: What if a refresh token is stolen? Reuse-detect: presenting a revoked token nukes all the user's tokens.
  • Q: How is the audit log made tamper-proof? DB trigger blocks UPDATE/DELETE + REVOKE on app_runtime.
  • Q: How are BYOK keys protected? Fernet symmetric encryption, key in env, plaintext never leaves the server.
