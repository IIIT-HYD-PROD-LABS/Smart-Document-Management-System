HOW THE API WORKS

REST · JSON · JWT-Bearer · X-Client-Id header for tenant · /docs in dev only · 14 compliance routers

★ REMEMBER

  • 5 v1 routers + 14 compliance + 6 email
  • Always JWT in Authorization
  • Tenant via X-Client-Id
  • 202 = enqueued, poll for result
  • 422 = OUT_OF_SCOPE on AI

STATUS CODES YOU'LL SEE

  • 200/201/204 happy paths
  • 202 upload accepted, work enqueued
  • 207 bulk partial-success
  • 400 bad input · 401 bad token · 403 AuthZ deny
  • 409 conflict (e.g. email exists, OAuth-link refused)
  • 422 Pydantic validation OR AI OUT_OF_SCOPE
  • 429 rate limit · 503 DB/redis down
