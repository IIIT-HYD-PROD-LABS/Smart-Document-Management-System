## Regenerating exports

The `.html` / `.pdf` / `.docx` files under `exports/` are build artifacts; do not edit by hand.

```bash
python scripts/build_features_docx.py    # → docs/exports/PRODUCT_FEATURES.docx
python scripts/build_features_pdf.py     # → docs/exports/PRODUCT_FEATURES.{html,pdf}
python scripts/build_tech_pdf.py         # → docs/exports/TaxSync_Technical_Documentation.{html,pdf}
python scripts/md_to_docx.py             # → docs/exports/Smart_Document_Management_System_Status_Report.docx
```
